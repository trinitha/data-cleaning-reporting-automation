# Data Cleaning & Reporting Automation

## Objective

To clean raw data and generate automated reports for better analysis.

## Tools Used

* Python
* Google Colab
* Pandas
* Matplotlib

## Project Description

This project focuses on cleaning employee data by removing duplicate values and handling missing values. It also generates an automated report summary and visualizes the cleaned data using graphs.

## Methodology

1. Loaded employee dataset.
2. Removed duplicate records.
3. Filled missing values.
4. Generated report summary.
5. Created visualization for salary analysis.

## Output

* Original Data
* Cleaned Data
* Report Summary
* Salary Graph Visualization

## Conclusion

This project successfully demonstrates data cleaning and reporting automation using Python.
